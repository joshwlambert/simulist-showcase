# Epiverse-TRACE {simulist} showcase

This repository contains the presentation and script for the Epiverse-TRACE showcase May 2025.

The quarto presentation is `simulist-showcase.qmd`, the HTML version is `simulist-showcase.html`.

The images in the presentation are in `images/`. 

The quarto presentation uses a custom theme: `ss-theme.scss`.

The R script for the interactive session in the showcase is `simulist-showcase-script.R`.
